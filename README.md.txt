# Manual Testing Projects

## 📌 Overview

This repository contains my **Manual Software Testing projects**, created to practice and demonstrate fundamental software testing concepts and techniques.

The projects include test case preparation, functional testing, positive and negative test scenarios, validation of user inputs, and verification of expected results against actual results.

---

## 📂 Projects

### 1. Revive Lifecare

**File:** `Manual Individual project.xlsx`

Manual testing of the Revive Lifecare website/application with a focus on validating important user functionalities.

**Testing activities include:**
- Functional behavior verification
- Positive and negative test scenario execution
- User input and field validation
- Boundary condition analysis

## 📝 Test Case Structure

The test cases are documented using a structured format containing:

| Field | Description |
|---|---|
| Test Case ID | Unique identifier for the test case |
| Test Scenario | Functionality being tested |
| Test Steps | Steps to execute the test |
| Test Data | Data used during testing |
| Expected Result | Expected behavior of the application |
| Actual Result | Actual behavior observed |
| Status | Pass / Fail |
